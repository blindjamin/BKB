# @bkb/tokens · Sistema de Diseño BKB v1.0

Paquete de tokens de diseño oficial para BKB (Sitio público y Portal de clientes).

## Principios
- **Cobre Electrolítico (`copper-700` #B4470F):** El color primario de acción de ingeniería.
- **Papel Técnico (`paper-50` #FBF8F5):** Lienzo cálido de fondo sin grises artificiales.
- **Tinta Industrial (`ink-900` #1A1513):** Tinta principal con contraste AAA.
- **Tipografía Técnica:** `Space Grotesk` para display y números, `IBM Plex Sans` para lectura en faena, y `IBM Plex Mono` para códigos SEC, RUT y mediciones.

## Uso
Importar en cualquier aplicación web o componente:
```css
@import "@bkb/tokens";
```
O directamente en el archivo CSS global del proyecto.
